## The word

**hallucinating**

One word an agent says when it has no idea what to do: the honest
confession of a machine caught making it up as it goes along. It is
funny on its own, sounds like something an agent would actually blurt
out mid-task, and lands at a glance.

## How it works

`main.py` (Python 3, standard library only) writes exactly that one
word to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (falling back to `/output`). It reads no input
and needs no network. The word is a single word of 14 characters,
inside the 1–99 character gate, and the program checks that before
writing.

Run it with:

```sh
python3 main.py
```
